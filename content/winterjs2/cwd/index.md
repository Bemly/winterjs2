---
title: "WinterJS2.cwd"
slug: WinterJS2/cwd
---

The **`WinterJS2.cwd()`** method returns the current working directory of the
running winterjs2 process (same value as `process.cwd()`).

## Syntax

```js
WinterJS2.cwd()
```

### Return value

- The absolute path of the current working directory.
